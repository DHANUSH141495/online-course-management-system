## 📖 Overview

**NovaLuxe** is a responsive, feature-complete modern E-Commerce web application built with clean semantic HTML5, pure CSS3 design systems, and vanilla ES6 JavaScript.

It features a 24-product catalog, real-time multi-filter search engine, slide-out shopping cart drawer, promo code discounts, product detail modal with image carousels and swatches, full checkout simulation with receipt printing, persistent wishlist, and order tracking.

---

## ✨ Key Store Features

| Feature | Description |
| :--- | :--- |
| **🛍️ 24+ Curated Products** | Real lifestyle photography across Tech, Smart Wearables, Apparel, Home & Living, Gaming, and Accessories. |
| **🔍 Search & Filter Engine** | Real-time search with instant clear button, category pills, price range slider, and sort dropdown. |
| **🛒 Interactive Cart Drawer** | Slide-out cart with quantity modifiers, Free Shipping Progress Bar ($75 threshold), and coupon engine. |
| **🏷️ Promo Code System** | Supports `NOVA25` (25% off), `WELCOME10` (10% off), and `FREESHIP` (Free Shipping). |
| **📦 Product Quick-View Modal** | High-res gallery thumbnails, color swatches, size selector, stock counters, and customer reviews. |
| **🔒 3-Step Checkout Simulation** | Shipping address, payment method selection (Card / UPI / COD), and instant printable receipt. |
| **❤️ Wishlist & Order History** | Save favorites with 1-click "Move All to Cart", plus live order status tracking (*Processing -> Delivered*). |
| **🌙 Dark / Light Mode** | Persistent theme toggle with rich color tokens and glassmorphic UI. |
| **💱 Currency Switcher** | 1-click switch between **$ USD** and **₹ INR** with dynamic exchange rate calculation. |

## 🚀 Active Demo Promo Codes

## 🛠️ Technology Stack

- **Core**: HTML5, Vanilla CSS3 (Custom Properties, Grid, Flexbox, Animations), Vanilla JavaScript (ES6+ Classes & LocalStorage).
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Space Grotesk*).
- **Icons & Assets**: Curated Unsplash HD photography & DiceBear Avatars.

---

## 🚀 How to Run

1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
2. Or serve locally with any live server:
   ```bash
   npx serve .
   ```
